Detailed Description

Controladora responsável pela gestão dos serviços CRUD e Listar das entidades Quadros e Cartões de Atividade.

Centraliza as operações de serviço responsáveis pelo manejamento de quadros, bem como os cartões de atividade que os compõem. Além disso, é responsável pelo cálculo das métricas de cartões de atividade.

)
overridevirtual

Promove a transição de estado de um cartão no fluxo Kanban.

Realiza as movimentações permitidas pelo sistema (A FAZER -> FAZENDO e FAZENDO -> FEITO). Ao mover para FAZENDO, valida se a quantidade de cartões em execução não excede o Limite de WIP do Quadro e grava a marca temporal no atributo de início. Ao mover para FEITO, registra a marca temporal no atributo de término.

Parameters
idCartaoIdentificador da atividade a ser movimentada.
novoEstadoInstância com o novo estado de destino.
momentoAtualInstância de Timestamp registrando o momento da transição.
Returns
true Se a movimentação for realizada com sucesso.
false Caso a transição seja inválida ou o limite de WIP seja excedido.

Implements ISerQuadros.

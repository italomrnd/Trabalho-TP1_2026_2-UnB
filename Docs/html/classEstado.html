Detailed Description

Classe que define a condição de uma tarefa a ser representada no sistema. Define o status de uma tarefa no sistema. O valor só pode ser definido como:

  • A FAZER
  • FAZENDO
  • FEITO Qualquer outra definição diferente destas é considerada inválida.

Detailed Description

Classe que define um código de identificação para entidades do sistema.

Define códigos de identificação única para entidades como Quadro, Projeto e Cartão de Atividade. Regras de formatação:

  • Possui 6 caracteres;
  • Os três primeiros caracteres são letras (a-z ou A-Z)
  • Os três últimos caracteres são dígitos (0-9).

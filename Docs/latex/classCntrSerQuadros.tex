\doxysubsection{Detailed Description}
Controladora responsável pela gestão dos serviços CRUD e Listar das entidades Quadros e Cartões de Atividade. 

Centraliza as operações de serviço responsáveis pelo manejamento de quadros, bem como os cartões de atividade que os compõem. Além disso, é responsável pelo cálculo das métricas de cartões de atividade.

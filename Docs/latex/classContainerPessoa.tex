\doxysubsection{Detailed Description}
Classe que representa o armazenamento de instâncias da classe \doxylink{classPessoa}{Pessoa}. 

A classe utiliza da estrutura mapa para armazenar as instâncias e facilitar o encontro e remoção dessas utilizando o \doxylink{classEmail}{Email} como chave primária de procura.

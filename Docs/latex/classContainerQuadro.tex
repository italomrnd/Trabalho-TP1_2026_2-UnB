\doxysubsection{Detailed Description}
Classe que representa o armazenamento de instâncias da classe \doxylink{classQuadro}{Quadro}. 

A classe utiliza da estrutura mapa para armazenar as instâncias e facilitar o encontro e remoção dessas utilizando o \doxylink{classIdentificador}{Identificador} como chave primária de procura.

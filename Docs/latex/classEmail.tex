\doxysubsection{Detailed Description}
Classe que representa o endereço de correio eletrônico de um usuário do sistema. 

Formato válido\+: parte-\/local@dominio

Regras para a parte local (máx. 64 caracteres)\+:
\begin{DoxyItemize}
\item Só aceita caracteres minúsculos;
\item Contém apenas letras (a-\/z), dígitos (0-\/9), ponto(.) ou hífen(-\/);
\item Não pode iniciar nem terminar com ponto(.) ou hífen(-\/);
\item Todo ponto ou hífen deve ser seguido imediatamente por número ou letra, ou seja, não é permitido dois hífens ou pontos seguidos.
\end{DoxyItemize}

Regras para o domínio (máx. 255 caracteres)\+:
\begin{DoxyItemize}
\item Só aceita caracteres minúsculos;
\item Composto por uma ou mais partes separadas por ponto (.);
\item Cada parte possui apenas letras (a-\/z) ou dígitos (0-\/9);
\item Nenhuma parte pode iniciar ou terminar com hífen (-\/). 
\end{DoxyItemize}

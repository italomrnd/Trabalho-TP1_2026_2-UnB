\doxysubsection{Detailed Description}
Classe que define um código de identificação para entidades do sistema. 

Define códigos de identificação única para entidades como \doxylink{classQuadro}{Quadro}, \doxylink{classProjeto}{Projeto} e Cartão de Atividade. Regras de formatação\+:
\begin{DoxyItemize}
\item Possui 6 caracteres;
\item Os três primeiros caracteres são letras (a-\/z ou A-\/Z)
\item Os três últimos caracteres são dígitos (0-\/9). 
\end{DoxyItemize}

\doxysubsection{Detailed Description}
Classe que representa uma sequência de caracteres alfanuméricos usada para proteger e liberar o acesso de um usuário do sistema. 


\begin{DoxyItemize}
\item Possui exatamente 5 caracteres;
\item Caractere por ser letra (a-\/z ou A-\/Z) ou dígito (0-\/9);
\item Existe pelo menos uma letra e um dígito; 
\end{DoxyItemize}

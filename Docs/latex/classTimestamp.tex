\doxysubsection{Detailed Description}
de caracteres ou números que identifica quando um evento específico ocorreu.

Pode descrever início ou término de um cartão de atividade, instante de entrada do cartão de atividade, bem como início ou término de um projeto. Regras de formatação\+:
\begin{DoxyItemize}
\item Segue o formato DIA-\/\+MES-\/\+ANO-\/\+HORARIO
\item DIA é número de 1 a 31;
\item MES é sigla JAN, FEV, MAR, ABR, MAI, JUN, JUL, AGO, SET, OUT, NOV, DEZ;
\item ANO é número de 2000 A 2099;
\item HORÁ\+RIO é valor de 00\+:00 a 23\+:59;
\item A data é válida considerando anos bissextos. 
\end{DoxyItemize}
